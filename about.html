🛡️ WEAPON DETECTION — SYSTEM OVERVIEW

WeaponDetection is an advanced security platform powered by a custom-trained YOLOv8M deep learning model. It is designed to detect weapons — including knives, guns — in real-time from live camera feeds, uploaded images, and video files.


The system uses computer vision techniques to identify threats at speed, making it suitable for surveillance, security screening, and public safety applications.


Capabilities: Live CCTV monitoring · Image threat scanning · Video file analysis · Multi-user access control · Detection history logging
